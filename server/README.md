# Servidor (fase 2)

Aquí irá el servidor Node.js + Socket.IO: multijugador, varias salas, login simple,
persistencia en SQLite y moderación del chat.

En la fase 1 está vacío: el cliente usa un `LocalTransport` que simula el servidor
dentro del navegador. El servidor reutilizará el `reducer` y el A* de `/shared`.
